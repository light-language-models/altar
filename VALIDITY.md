## Interpretation discipline

- **Mechanism:** inputs and transformations performed by software.
- **Reproducibility:** whether independent implementations return the same receipt.
- **Correspondence:** whether blinded judges distinguish true question–symbol pairings from controls.
- **Answer influence:** whether hidden field access changes measured response properties.
- **Causation:** why an effect occurs; never inferred merely from correspondence.

The local neighboring-time series in historical Aethyr data is interesting but
not confirmed: one semantic judge showed a signal while an embedding control did
not. Exact-time and full-field primary tests did not show support in that run.
This motivates a better prospective playtest; it does not establish
correspondence. Metaphysics remains an optional interpretive frame, not a
conclusion of these measurements.
